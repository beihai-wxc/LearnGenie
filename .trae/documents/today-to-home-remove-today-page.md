# 侧边栏"今天学点什么"跳转到首页并删除旧 /today 页面

## 当前状态
- 侧边栏"今天学点什么"按钮指向 `/today`，跳转到 `app/today/page.tsx`
- `app/today/page.tsx` 是一个包含"今日已完成"和"为你推荐"列表的独立页面
- `app/page.tsx` (首页) 显示用户截图中"今天想学点什么"的大标题 + 输入框界面

## 修改内容

### 1. 修改 `components/sidebar/sidebar.tsx`
将"今天学点什么"条目的 path 从 `/today` 改为 `/`（首页）

### 2. 删除 `app/today/page.tsx`
该页面不再需要，删除整个文件。

## 预期效果
点击侧边栏"今天学点什么"时，导航到首页 (`/`)，显示截图中所示的"今天想学点什么"界面。旧的 `/today` 页面被移除。
