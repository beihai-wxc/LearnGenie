# 学生肖像页面可视化改造

## 修改内容

### 修改文件：`app/profile/page.tsx`

#### 1. 删除右上角"重置画像"按钮
- 移除 Header 区域的 `justify-between` 布局，改为居中或仅左侧
- 删除重置按钮及其 `handleReset` 函数
- 删除不再使用的 `RefreshCw` import
- 删除 `setLearningProfile` store 引用（不再需要重置）

#### 2. 将 8 个维度简要概括展示在标题下方
在"学生肖像"标题和副标题之间，新增一行 8 个维度的简要标签展示：
- 使用 Badge 或小型标签展示每个维度的名称和当前状态
- 有数据时显示维度的关键特征（如"视觉型学习者"、"内在动机"等）
- 无数据时显示"待了解"

具体展示格式（示例）：
```
知识基础：已掌握微积分基础  |  认知风格：视觉型  |  易错点：概念混淆  |  学习节奏：适中
兴趣方向：AI/编程  |  元认知：自我检查型  |  动机：内在驱动  |  交互偏好：带代码
```

#### 3. 替换维度卡片为多种可视化图表
删除原有的 4 列进度条卡片布局，改为以下可视化方案：

**方案：两行可视化图表**

**第一行（左侧）：极坐标柱状图（Nightingale Rose）**
- 使用 ECharts 的 polar 类型柱状图
- 8 个维度作为分类轴
- 分数作为半径值
- 每个维度使用不同颜色
- 尺寸：与雷达图同高，宽度占 50%

**第一行（右侧）：环形图（Donut Chart）**
- 展示 8 个维度的分数占比
- 中心显示平均分
- 鼠标悬停显示详情
- 尺寸：与雷达图同高，宽度占 50%

**第二行：分组柱状图（Grouped Bar Chart）**
- 8 个维度的横向柱状对比
- 维度标签在左侧，柱状图水平延伸
- 每根柱子显示具体分数值
- 按分数从高到低排序
- 全宽显示

#### 4. 新增图表容器 ref
- `roseChartRef` — 极坐标柱状图
- `donutChartRef` — 环形图
- `barChartRef` — 分组柱状图

#### 5. 新增 useEffect 初始化三个图表
每个图表独立 useEffect 或合并为一个统一处理

## 预期效果
- 页面更简洁（无重置按钮）
- 8 个维度的核心信息一目了然（简要概括行）
- 多种可视化图表丰富展示效果（雷达图 + 极坐标图 + 环形图 + 横向柱状图）
- 图表均响应学习画像数据变化
