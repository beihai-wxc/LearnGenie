# 机器学习基础与训练范式

> 机器学习是AI的核心分支，其核心目标是让计算机从数据中自动学习规律，并用于预测或决策。

---

## 一、机器学习的形式化定义

### 1.1 Tom Mitchell 的经典定义

> "一个计算机程序从经验E中学习，针对某类任务T，用性能度量P来衡量。如果在任务T上，经过经验E后，性能P有所提高，则称该程序对任务T进行了学习。"

**示例**：垃圾邮件分类
- 任务T：将邮件分类为"垃圾"或"正常"
- 经验E：历史邮件及其标签
- 性能P：分类准确率

### 1.2 机器学习的三大假设

1. **数据可表示**：现实世界的问题可以用数值特征表示
2. **模式存在**：数据中存在可学习的统计规律
3. **未来可预测**：训练数据的分布与未来数据的分布相似（IID假设）

> 当第三个假设被违反时（分布偏移），模型性能会急剧下降。这是AI落地中最常见的失败原因之一。

## 二、三大范式对比

### 2.1 直观类比

**监督学习 → 有标准答案的考试**
- 每个样本都有正确标签
- 模型通过大量带标样本训练
- 目标：最小化预测与标签之间的差异

**无监督学习 → 自主整理仓库**
- 所有样本都没有标签
- 系统自行发现数据的内在结构
- 目标：发现数据中的模式（聚类、降维）

**强化学习 → 机器人自主送货**
- 机器人通过与环境交互获得奖励
- 必须通过试错学习最优策略
- 目标：最大化长期累积奖励

### 2.2 数学形式化对比

| 维度 | 监督学习 | 无监督学习 | 强化学习 |
|------|---------|-----------|---------|
| **输入** | 特征 X + 标签 y | 仅特征 X | 状态 s |
| **输出** | 预测 ŷ | 结构/模式 | 动作 a |
| **反馈信号** | 真实标签（密集、即时） | 无外部反馈 | 奖励 r（稀疏、延迟） |
| **目标函数** | 最小化 L(ŷ, y) | 最大化内部一致性 | 最大化 E[Σγᵗrₜ] |
| **训练方式** | 批量训练 | 批量训练 | 在线交互式训练 |
| **核心挑战** | 标注成本高 | 评估困难 | 奖励稀疏/信用分配 |

## 三、监督学习详解

### 3.1 经验风险最小化 vs 结构风险最小化

**经验风险最小化（ERM）**：

$$\min_\theta \frac{1}{N} \sum_{i=1}^{N} L(f_\theta(x_i), y_i)$$

直接最小化训练集上的平均损失。问题是可能过拟合。

**结构风险最小化（SRM）**：

$$\min_\theta \frac{1}{N} \sum_{i=1}^{N} L(f_\theta(x_i), y_i) + \lambda \Omega(\theta)$$

在经验风险基础上加入正则化项 $\Omega(\theta)$，控制模型复杂度，防止过拟合。

### 3.2 偏差-方差权衡（详细推导）

对于平方损失，模型的期望泛化误差可以分解为：

$$\mathbb{E}[(y - \hat{f}(x))^2] = \text{Bias}^2[\hat{f}(x)] + \text{Var}[\hat{f}(x)] + \sigma^2$$

其中：
- **Bias²**：模型预测均值与真实值的偏差的平方 = $(\mathbb{E}[\hat{f}(x)] - f(x))^2$
- **Variance**：模型预测的方差 = $\mathbb{E}[(\hat{f}(x) - \mathbb{E}[\hat{f}(x)])^2]$
- **σ²**：数据的不可约噪声

**直觉理解**：

```
偏差高（打偏了）：模型系统性地偏离真实值
  → 解决：增加模型复杂度、添加特征

方差高（打散了）：模型对训练数据的小变化过于敏感
  → 解决：增加训练数据、正则化、简化模型

理想：低偏差 + 低方差（又准又稳）
```

| 状态 | 偏差 | 方差 | 现象 | 解决方案 |
|------|------|------|------|---------|
| **欠拟合** | 高 | 低 | 训练集和测试集表现都差 | 更复杂模型、更多特征 |
| **过拟合** | 低 | 高 | 训练集好但测试集差 | 正则化、更多数据、早停 |
| **理想** | 低 | 低 | 两边都好 | 恰当的模型复杂度 |

### 3.3 线性回归详解

**模型**：$\hat{y} = w^T x + b$

**损失函数（MSE）**：$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$

**闭式解（最小二乘法）**：

$$w^* = (X^TX)^{-1}X^Ty$$

**为什么MSE是最小二乘法的自然选择？**

从概率视角看，假设 $y = w^Tx + b + \epsilon$，其中噪声 $\epsilon \sim N(0, \sigma^2)$，则最大似然估计等价于最小化MSE。因此MSE不是随意选择的，而是在高斯噪声假设下的最优损失函数。

**线性回归的四大假设（Gauss-Markov条件）**：

| 假设 | 含义 | 违反后果 | 检验方法 |
|------|------|---------|---------|
| **线性性** | Y与X是线性关系 | 模型偏差大 | 残差vs拟合值图 |
| **独立性** | 误差项相互独立 | 标准误估计有偏 | Durbin-Watson检验 |
| **同方差性** | 误差方差恒定 | 置信区间不准 | Breusch-Pagan检验 |
| **正态性** | 误差服从正态分布 | 小样本推断不准 | Q-Q图、Shapiro检验 |

**正则化线性回归**：

当特征之间存在多重共线性或特征过多时，闭式解 $(X^TX)^{-1}$ 可能不稳定或不存在。正则化通过约束参数来解决：

**Ridge回归（L2正则化）**：

$$\min_w \frac{1}{n}\sum_{i=1}^{n}(y_i - w^Tx_i)^2 + \lambda \|w\|_2^2$$

闭式解变为：$w^* = (X^TX + \lambda I)^{-1}X^Ty$，其中 $I$ 是单位矩阵。$\lambda I$ 保证了矩阵始终可逆。

- **效果**：将参数往0方向压缩，但不会精确等于0
- **适用**：特征多且都有用，但系数值偏大时
- **直觉**：像弹簧把所有系数往0拉，但拉力有限

**Lasso回归（L1正则化）**：

$$\min_w \frac{1}{n}\sum_{i=1}^{n}(y_i - w^Tx_i)^2 + \lambda \|w\|_1$$

- **效果**：将部分参数压缩到精确的0，实现特征选择
- **适用**：特征多但只有少数真正有用时
- **直觉**：像一把刀，直接砍掉不重要的特征

**为什么L1产生稀疏解而L2不会？**

```
L2正则化的约束区域是圆：       L1正则化的约束区域是菱形：
     /\                           /\
    /  \                         /  \
   / ○  \  ← 最优解在边上       / ○  \  ← 最优解常在角上
  /      \                     /      \
  \      /                     \      /
   \    /                       \    /
    \  /                         \  /
     \/                           \/

菱形的角在坐标轴上，所以最优解常出现在w某个分量=0的位置 → 稀疏
```

**ElasticNet（L1+L2混合）**：

$$\min_w \frac{1}{n}\sum_{i=1}^{n}(y_i - w^Tx_i)^2 + \lambda_1 \|w\|_1 + \lambda_2 \|w\|_2^2$$

结合两者优点：既能特征选择，又能处理相关特征组。

from sklearn.preprocessing import StandardScaler

from sklearn.model_selection import cross_val_score

y = np.array([2.1, 3.9, 6.2, 7.8])

# 添加偏置列
X_b = np.c_[np.ones((4, 1)), X]
w_normal = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
print(f"正规方程解: w={w_normal[1]:.3f}, b={w_normal[0]:.3f}")

# 方式2：梯度下降
w = np.random.randn(2, 1)
lr = 0.01
for epoch in range(1000):
    y_pred = X_b @ w
    gradient = 2/4 * X_b.T @ (y_pred - y.reshape(-1, 1))
    w -= lr * gradient

print(f"梯度下降解: w={w[1,0]:.3f}, b={w[0,0]:.3f}")

# 方式3：sklearn（推荐）
# 普通线性回归
lr_model = LinearRegression().fit(X, y)

# Ridge回归（L2正则化）
# alpha越大，正则化越强，系数越接近0
ridge = make_pipeline(StandardScaler(), Ridge(alpha=1.0))
ridge.fit(X.reshape(-1, 1), y)

# Lasso回归（L1正则化）—— 特征选择
lasso = make_pipeline(StandardScaler(), Lasso(alpha=0.1))

# ElasticNet（L1+L2）

enet.fit(X.reshape(-1, 1), y)

# 选择最佳正则化参数
from sklearn.model_selection import GridSearchCV
param_grid = {'ridge__alpha': [0.01, 0.1, 1, 10, 100]}
grid = GridSearchCV(make_pipeline(StandardScaler(), Ridge()), param_grid, cv=5)

### 3.4 逻辑回归详解

**模型**：$P(y=1|x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^Tx+b)}}$

**损失函数（交叉熵）**：

$$L = -\frac{1}{n}\sum_{i=1}^{n} [y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)]$$

**为什么不用MSE做分类？**
1. MSE + Sigmoid → 梯度消失（当预测正确时梯度接近0）
2. 交叉熵 + Sigmoid → 梯度始终与误差成正比，学习更高效
3. 交叉熵是MLE在伯努利分布假设下的自然结果

**决策边界的概率解释**：

决策边界 $w^Tx + b = 0$ 将特征空间分为两个区域。距离决策边界越远的点，预测概率越接近0或1；边界附近的点概率接近0.5，表示模型"不确定"。

**决策边界的几何含义**：$w$ 是决策边面的法向量，$\|w\|$ 越大，概率从0.5到1的变化越陡峭（相当于Sigmoid变得更像阶跃函数）。

**多分类逻辑回归（Softmax回归）**：

$$P(y=k|x) = \frac{e^{w_k^Tx + b_k}}{\sum_{j=1}^{K} e^{w_j^Tx + b_j}}$$

损失函数为多类交叉熵：

$$L = -\frac{1}{n}\sum_{i=1}^{n} \sum_{k=1}^{K} \mathbb{1}[y_i=k] \log P(y=k|x_i)$$

**逻辑回归的正则化**：

sklearn中 `LogisticRegression` 默认使用L2正则化，参数 `C` 是正则化强度的倒数（C越大，正则化越弱）：

```python
# C=1.0 是默认值
# C很大(如100) → 几乎不正则化 → 可能过拟合
# C很小(如0.01) → 强正则化 → 可能欠拟合
model = LogisticRegression(C=1.0, penalty='l2')  # L2正则化
model = LogisticRegression(C=1.0, penalty='l1', solver='saga')  # L1正则化（特征选择）
```

**类不平衡处理**：

当正负样本比例悬殊时，逻辑回归会偏向多数类。解决方案：

| 方法 | 原理 | sklearn参数 |
|------|------|------------|
| **类权重调整** | 少数类的损失权重增大 | `class_weight='balanced'` |
| **过采样** | 复制少数类样本 | SMOTE |
| **欠采样** | 减少多数类样本 | RandomUnderSampler |
| **阈值调整** | 不用0.5，选择最优阈值 | PR曲线找最优点 |

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report

# 处理类不平衡
model = LogisticRegression(class_weight='balanced')  # 自动调整权重
model.fit(X_train, y_train)

# 查看权重：class_weight = n_samples / (n_classes * np.bincount(y))
# 如1000个样本，900负100正 → 正类权重 = 1000/(2*100) = 5，负类权重 = 1000/(2*900) ≈ 0.56

# 调整决策阈值
y_prob = model.predict_proba(X_test)[:, 1]
threshold = 0.3  # 降低阈值，增加召回率
y_pred = (y_prob >= threshold).astype(int)
```

```python
# 逻辑回归完整实现
class LogisticRegression:
    def __init__(self, lr=0.01, epochs=1000, lambda_reg=0.01):
        self.lr = lr
        self.epochs = epochs
        self.lambda_reg = lambda_reg  # L2正则化系数
    
    def sigmoid(self, z):
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))
    
    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.w = np.zeros(n_features)
        self.b = 0
        
        for _ in range(self.epochs):
            z = X @ self.w + self.b
            y_pred = self.sigmoid(z)
            
            # 梯度计算（含L2正则化，偏置不正则化）
            dw = (1/n_samples) * X.T @ (y_pred - y) + self.lambda_reg * self.w
            db = (1/n_samples) * np.sum(y_pred - y)
            
            # 参数更新
            self.w -= self.lr * dw
            self.b -= self.lr * db
    
    def predict_proba(self, X):
        return self.sigmoid(X @ self.w + self.b)
    
    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X) >= threshold).astype(int)
```

### 3.5 SVM 详解

**核心思想**：找到使两类样本间隔最大的超平面。

**最大间隔的几何直觉**：

超平面 $w^Tx + b = 0$ 将空间分为两类。间隔（margin）是离超平面最近的样本到超平面的距离：

$$\text{margin} = \frac{2}{\|w\|}$$

最大化间隔等价于最小化 $\|w\|$：

$$\max_{w,b} \frac{2}{\|w\|} \quad \text{s.t.} \quad y_i(w^Tx_i+b) \geq 1, \forall i$$

等价于：

$$\min_{w,b} \frac{1}{2}\|w\|^2 \quad \text{s.t.} \quad y_i(w^Tx_i+b) \geq 1, \forall i$$

**为什么约束是 $y_i(w^Tx_i+b) \geq 1$ 而不是 $> 0$？**

通过缩放 $w$ 和 $b$，总可以使得最近的样本满足 $y_i(w^Tx_i+b) = 1$（这叫"函数间隔"归一化到1）。这样间隔就只由 $\|w\|$ 决定。

**对偶问题**：

利用拉格朗日乘子法，将约束优化转化为对偶问题：

$$\max_\alpha \sum_i \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^T x_j$$

$$\text{s.t.} \quad \alpha_i \geq 0, \quad \sum_i \alpha_i y_i = 0$$

**对偶问题的关键性质**：
- 目标函数只依赖内积 $x_i^T x_j$，这为核技巧奠定了基础
- **KKT互补松弛条件**：$\alpha_i(y_i(w^Tx_i+b)-1) = 0$。只有支持向量（$y_i(w^Tx_i+b)=1$）对应的 $\alpha_i > 0$，其余样本的 $\alpha_i = 0$
- 这意味着**SVM的决策只依赖少数支持向量**，具有稀疏性

**软间隔SVM（处理线性不可分）**：

引入松弛变量 $\xi_i$，允许部分样本违反间隔约束：

$$\min_{w,b,\xi} \frac{1}{2}\|w\|^2 + C\sum_i \xi_i$$
$$\text{s.t.} \quad y_i(w^Tx_i+b) \geq 1 - \xi_i, \quad \xi_i \geq 0$$

$C$ 是正则化参数：C大→少容忍错误（可能过拟合），C小→多容忍错误（可能欠拟合）。

**核技巧**：当数据线性不可分时，将数据映射到高维空间。

$$K(x_i, x_j) = \phi(x_i)^T \phi(x_j)$$

关键：不需要显式计算 $\phi(x)$，只需计算核函数 $K$。

| 核函数 | 公式 | 适用场景 | 直觉 |
|--------|------|---------|------|
| **线性核** | $K(x, z) = x^Tz$ | 线性可分 | 原始空间分类 |
| **多项式核** | $K(x, z) = (x^Tz + c)^d$ | 非线性特征组合 | 添加多项式特征 |
| **RBF核** | $K(x, z) = \exp(-\gamma\|x-z\|^2)$ | 通用非线性 | 相似度衰减 |
| **Sigmoid核** | $K(x, z) = \tanh(\alpha x^Tz + c)$ | 类似神经网络 | 神经元激活 |

**RBF核的直觉**：$K(x,z)$ 衡量 $x$ 和 $z$ 的相似度。当 $x$ 和 $z$ 很近时，$K \to 1$；很远时，$K \to 0$。$\gamma$ 控制衰减速度：$\gamma$ 大→只有非常近的才算相似。

```python
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import GridSearchCV

# SVM分类（推荐先标准化！）
clf = make_pipeline(StandardScaler(), SVC(kernel='rbf', C=1.0, gamma='scale'))
clf.fit(X_train, y_train)

# C参数：正则化强度
# C大 → 更少容忍分类错误（可能过拟合）
# C小 → 更多容忍分类错误（可能欠拟合）
# gamma参数：RBF核的影响范围
# gamma大 → 每个样本影响范围小（可能过拟合）
# gamma小 → 每个样本影响范围大（可能欠拟合）

# 超参数搜索
param_grid = {
    'svc__C': [0.1, 1, 10, 100],
    'svc__gamma': ['scale', 0.01, 0.1, 1],
}
grid_search = GridSearchCV(clf, param_grid, cv=5, scoring='f1')
grid_search.fit(X_train, y_train)
print(f"最佳参数: {grid_search.best_params_}")
```

### 3.6 决策树详解

**核心思想**：递归地选择最优特征进行分裂，将数据划分为越来越纯的子集。

**信息熵的直觉**：熵衡量数据的"混乱程度"。纯数据（只有一类）熵为0，均匀分布的数据熵最大。

$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

| 数据分布 | 熵值 | 含义 |
|---------|------|------|
| [1, 1, 1, 1] | 0 | 完全纯净 |
| [0.5, 0.5] | 1.0 | 最混乱（二分类） |
| [0.9, 0.1] | 0.47 | 较纯净 |
| [0.25, 0.25, 0.25, 0.25] | 2.0 | 最混乱（四分类） |

**分裂准则**：

| 准则 | 公式 | 特点 |
|------|------|------|
| **信息增益** | $IG = H(D) - \sum \frac{|D_v|}{|D|}H(D_v)$ | ID3算法，偏好多值特征 |
| **信息增益率** | $IGR = IG / IV$ | C4.5算法，克服多值偏好 |
| **基尼指数** | $Gini(D) = 1 - \sum p_k^2$ | CART算法，计算更快 |

**信息增益为什么偏好多值特征？**

如果一个特征有很多值（如"日期"），每个值对应的子集很小，子集可能很纯，信息增益很高，但这样的分裂没有泛化能力。信息增益率通过除以"固有值"(IV)来惩罚这种情况：

$$IV = -\sum_{v=1}^{V} \frac{|D_v|}{|D|} \log_2 \frac{|D_v|}{|D|}$$

```python
# 信息熵和基尼指数的计算
import numpy as np

def entropy(y):
    """计算信息熵"""
    _, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)
    return -np.sum(probs * np.log2(probs + 1e-10))

def gini(y):
    """计算基尼指数"""
    _, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)
    return 1 - np.sum(probs ** 2)

def info_gain(X_col, y, threshold):
    """计算按threshold二分后的信息增益"""
    n = len(y)
    left_mask = X_col <= threshold
    right_mask = ~left_mask
    
    if left_mask.sum() == 0 or right_mask.sum() == 0:
        return 0
    
    n_left, n_right = left_mask.sum(), right_mask.sum()
    H_parent = entropy(y)
    H_left = entropy(y[left_mask])
    H_right = entropy(y[right_mask])
    
    return H_parent - (n_left / n) * H_left - (n_right / n) * H_right

# 示例
y = [0, 0, 0, 1, 1, 1, 1, 1]  # 3个类别0，5个类别1
print(f"信息熵: {entropy(y):.4f}")  # 0.9544
print(f"基尼指数: {gini(y):.4f}")   # 0.4688

# 寻找最佳分裂点
X_col = np.array([2.5, 3.0, 3.5, 4.0, 5.5, 6.0, 6.5, 7.0])
thresholds = np.sort(np.unique((X_col[:-1] + X_col[1:]) / 2))  # 候选分裂点
best_threshold = max(thresholds, key=lambda t: info_gain(X_col, np.array(y), t))
print(f"最佳分裂点: {best_threshold}, 信息增益: {info_gain(X_col, np.array(y), best_threshold):.4f}")
```

**决策树的剪枝**：

决策树容易过拟合——树太深会"记住"训练数据的噪声。剪枝方法：

| 方法 | 原理 | 实现 |
|------|------|------|
| **预剪枝** | 分裂前判断是否应该分裂 | max_depth, min_samples_split |
| **后剪枝** | 先建完整棵树，再从底向上剪枝 | cost-complexity pruning |
| **正则化** | 限制树的复杂度 | min_samples_leaf, max_leaf_nodes |

**代价复杂度剪枝（CCP）**：

$$R_\alpha(T) = R(T) + \alpha |T|$$

其中 $R(T)$ 是训练误差，$|T|$ 是叶节点数，$\alpha$ 控制惩罚强度。$\alpha$ 越大，树越简单。

### 3.7 集成学习

集成学习是机器学习中最重要的实践方法之一。核心思想：**多个弱学习器组合成一个强学习器**。

**理论基础——Condorcet陪审团定理**：如果每个陪审员独立做出正确判断的概率大于50%，则多数投票的正确概率随陪审员数量增加而趋向100%。

**三个关键条件**：
1. **个体学习器要好于随机猜测**（准确率 > 50%）
2. **学习器之间要有差异性**（不同类型错误）
3. **组合方式要合理**（投票、加权平均等）

#### 3.7.1 Bagging（Bootstrap Aggregating）

训练多个独立模型，投票/平均。

**Bootstrap采样**：从n个样本中有放回地随机抽取n个样本。约63.2%的原始样本会被采到（$1 - (1-1/n)^n \to 1-1/e \approx 0.632$），未被采到的36.8%构成OOB（Out-of-Bag）样本。

- 代表：**随机森林**
- 每棵树使用随机采样的数据和随机选择的特征
- **OOB（Out-of-Bag）估计**：未被采样的数据用于评估，无需额外验证集
- **袋外误差**是对泛化误差的无偏估计

**随机森林的随机性来源**：
1. **样本随机**：每棵树使用不同的Bootstrap采样
2. **特征随机**：每次分裂只考虑 $\sqrt{p}$ 个随机特征（p是总特征数）
3. 两种随机性的叠加使树之间的相关性大大降低

#### 3.7.2 Boosting

序列训练多个模型，每个模型关注前一个模型的错误。

- 代表：**AdaBoost、GBDT、XGBoost、LightGBM、CatBoost**
- 核心思想：给之前分错的样本更高权重

**AdaBoost算法**：

```python
class AdaBoost:
    """AdaBoost二分类器"""
    def __init__(self, n_estimators=50):
        self.n_estimators = n_estimators
        self.alphas = []   # 每个弱学习器的权重
        self.models = []   # 弱学习器列表
    
    def fit(self, X, y):
        n = len(y)
        weights = np.ones(n) / n  # 初始化样本权重
        
        for t in range(self.n_estimators):
            # 训练弱学习器（决策树桩）
            stump = DecisionStump()
            stump.fit(X, y, sample_weight=weights)
            y_pred = stump.predict(X)
            
            # 计算加权错误率
            incorrect = (y_pred != y)
            err = np.dot(weights, incorrect)
            
            # 计算弱学习器权重
            alpha = 0.5 * np.log((1 - err) / (err + 1e-10))
            
            # 更新样本权重
            weights *= np.exp(-alpha * y * y_pred)
            weights /= weights.sum()  # 归一化
            
            self.alphas.append(alpha)
            self.models.append(stump)
    
    def predict(self, X):
        # 加权投票
        predictions = sum(alpha * model.predict(X) 
                         for alpha, model in zip(self.alphas, self.models))
        return np.sign(predictions)
```

**GBDT（梯度提升决策树）**：

不是修改样本权重，而是让每棵新树拟合前一轮的**残差**（负梯度）：

$$F_{t+1}(x) = F_t(x) + \eta \cdot h_t(x)$$

其中 $h_t$ 是拟合残差的新树，$\eta$ 是学习率（shrinkage）。

**XGBoost vs LightGBM vs CatBoost**：

| 特性 | XGBoost | LightGBM | CatBoost |
|------|---------|----------|----------|
| 树生长策略 | Level-wise（按层） | **Leaf-wise**（按叶子） | Level-wise + 对称 |
| 分裂算法 | 预排序 | **直方图加速** | 直方图 + 有序提升 |
| 类别特征 | 需要手动编码 | 支持但需编码 | **原生支持** |
| 训练速度 | 较慢 | 快 | 中等 |
| 过拟合控制 | 较好 | 需注意（Leaf-wise易过拟合） | 较好 |
| 适用场景 | 中小数据集 | 大数据集 | 类别特征多 |

**LightGBM的Leaf-wise策略**：

```
Level-wise（XGBoost）：        Leaf-wise（LightGBM）：
      [A]                           [A]
     /   \                         /   \
   [B]   [C]                     [B]   [C]
   / \   / \                     / \     |
 [D][E][F][G]                 [D][E]   [H]  ← 继续分裂增益最大的叶子
                                   |
                                  [H]     ← 增益更大的路径更深
```

Leaf-wise优先分裂增益最大的叶子，可能长出不对称的深树，精度更高但更容易过拟合。

|------|------|---------|---------|-----------|
| **Bagging** | 并行训练独立模型 | — | ✅ | 低 |

### 3.8 特征工程

特征工程是传统机器学习中最关键的一步。**"数据和特征决定了机器学习的上限，模型和算法只是逼近这个上限"**。

#### 3.8.1 数值特征处理

**特征缩放**：不同量纲的特征会导致模型偏向数值大的特征。

| 方法 | 公式 | 适用场景 | 对异常值 |
|------|------|---------|---------|
| **StandardScaler** | $(x-\mu)/\sigma$ | 数据近似正态分布 | 敏感 |
| **MinMaxScaler** | $(x-x_{min})/(x_{max}-x_{min})$ | 数据有明确上下界 | 非常敏感 |
| **RobustScaler** | $(x-Q_2)/(Q_3-Q_1)$ | 数据有异常值 | **鲁棒** |
| **Log变换** | $\log(1+x)$ | 数据右偏/长尾 | 压缩极端值 |

```python

```

# Target Encoding（注意：必须在交叉验证循环内计算，否则会数据泄露！）
def target_encode_kfold(df, col, target, n_splits=5):
    """K折Target Encoding，避免数据泄露"""
    from sklearn.model_selection import KFold
    df[f'{col}_target_enc'] = np.nan
    kf = KFold(n_splits=n_splits, shuffle=True, random_state=42)
    
    for train_idx, val_idx in kf.split(df):
        # 用训练集计算每个类别的目标均值
        means = df.iloc[train_idx].groupby(col)[target].mean()
        # 在验证集上编码
        df.iloc[val_idx, df.columns.get_loc(f'{col}_target_enc')] = \
            df.iloc[val_idx][col].map(means)
    
    # 全局均值填充未知类别
    global_mean = df[target].mean()
    df[f'{col}_target_enc'] = df[f'{col}_target_enc'].fillna(global_mean)
    return df

## 四、无监督学习详解

### 4.1 K-means 详解

**算法步骤**：
1. 随机初始化K个聚类中心
2. 将每个样本分配到最近的聚类中心
3. 更新聚类中心为所属样本的均值
4. 重复2-3直到收敛

**数学目标**：最小化簇内距离之和

$$J = \sum_{k=1}^{K} \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

**算法的收敛性**：K-means保证每次迭代J不增加（因为步骤2和步骤3都使J减小或不变），但只能收敛到局部最优，不保证全局最优。

**K-means++初始化**：改进的初始化策略，选择距离已有中心尽量远的新中心。

```
K-means++ 初始化过程：
1. 随机选一个样本作为第一个中心 μ₁
2. 对每个样本x，计算到最近中心的距离 D(x) = min||x - μᵢ||
3. 以概率 D(x)²/ΣD(x')² 选择下一个中心（距离越远越可能被选）
4. 重复2-3直到选出K个中心
```

```python
from sklearn.cluster import KMeans
import numpy as np

# K-means
kmeans = KMeans(n_clusters=3, init='k-means++', n_init=10)
labels = kmeans.fit_predict(X)

# 关键属性
print(f"聚类中心: {kmeans.cluster_centers_}")
print(f"簇内距离之和(Inertia): {kmeans.inertia_:.2f}")
print(f"迭代次数: {kmeans.n_iter_}")

# 选择最优K值
```

**确定K值的方法**：

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **肘部法则** | 画Inertia vs K曲线，选拐点 | 直观 | 拐点不明显 |
| **轮廓系数** | 衡量聚类的紧密度和分离度 | 有客观标准 | 计算成本高 |
| **Gap Statistic** | 比较实际与随机分布的Inertia | 理论更严谨 | 需要生成参考分布 |
| **业务需求** | 根据业务场景决定K | 最实用 | 主观 |

from sklearn.metrics import silhouette_score
for k in range(2, 11):
    km = KMeans(n_clusters=k, n_init=10)
    labels = km.fit_predict(X)
    score = silhouette_score(X, labels)
    print(f"K={k}, 轮廓系数={score:.4f}")
```

**K-means的局限与替代方案**：

| 局限 | 原因 | 替代方案 |
|------|------|---------|
| 只能发现球形簇 | 使用欧氏距离 | **DBSCAN**（任意形状） |
| 需要预设K | 算法本身不知道K | DBSCAN、层次聚类 |
| 对异常值敏感 | 均值受异常值影响 | **K-medoids**（用中位数点） |
| 各簇大小不同时效果差 | 等概率假设 | GMM（高斯混合模型） |

**DBSCAN详解**：

```
DBSCAN核心概念：
- 核心点：半径ε内至少有min_samples个邻居
- 边界点：在核心点的ε半径内，但自身邻居不足
- 噪声点：既非核心也非边界 → 被视为异常值

优势：自动确定簇数、能发现任意形状、识别异常值
```

# DBSCAN聚类

# label=-1 表示噪声点（异常值）

# 调参：eps太小→太多噪声点；eps太大→所有点变成一个簇
# 可用k-distance图选择eps
from sklearn.neighbors import NearestNeighbors

# 画图，选拐点处作为eps
```

**GMM（高斯混合模型）**：

K-means的"软分类"版本，每个样本以概率属于每个簇：

$$P(x_i \in C_k) = \frac{\pi_k \mathcal{N}(x_i | \mu_k, \Sigma_k)}{\sum_j \pi_j \mathcal{N}(x_i | \mu_j, \Sigma_j)}$$

```python

# GMM聚类（软分类）

# 选择最佳K值（用BIC/AIC，越小越好）
bics = []
for k in range(1, 11):
    gmm = GaussianMixture(n_components=k)
    gmm.fit(X)
    bics.append(gmm.bic(X))

```

### 4.2 PCA 详解

**PCA的两种等价理解**：
1. 找到使数据方差最大的正交方向（最大化投影方差）
2. 找到使重构误差最小的低维表示（最小化重构误差）

**PCA的数学推导**：

1. 数据中心化：$\tilde{X} = X - \mu$
2. 计算协方差矩阵：$C = \frac{1}{n}\tilde{X}^T\tilde{X}$
3. 特征分解：$C = V\Lambda V^T$
4. 选择前k个最大特征值对应的特征向量 $V_k$
5. 投影：$Z = \tilde{X}V_k$

**为什么最大特征值对应的方向方差最大？**

协方差矩阵 $C$ 的第i个特征值 $\lambda_i$ 恰好等于数据在第i个特征向量方向上的方差。因此选择最大特征值对应的特征向量，就是选择方差最大的方向。

**特征值与方差解释比例**：

$$\text{第i主成分的方差解释比例} = \frac{\lambda_i}{\sum_{j=1}^{d}\lambda_j}$$

例如：3个特征值 [4, 1, 0.5]，则第一主成分解释了 $4/(4+1+0.5) = 72.7\%$ 的方差。

**PCA的步骤详解与直觉**：

```
原始数据（2D）：       PCA投影后（1D）：

    ·  ·               ·
   · · · ·      →     · · · ·
  ·  · · ·            · · · ·
    ·  ·                 · ·

找到方差最大的方向（红线），将数据投影到该方向上
投影后的数据虽然只有1维，但保留了最多的信息
```

```python
from sklearn.decomposition import PCA
import numpy as np

# PCA降维
pca = PCA(n_components=0.95)  # 保留95%的方差（自动选择维度）
X_reduced = pca.fit_transform(X)
print(f"原始维度: {X.shape[1]}")
print(f"降维后: {X_reduced.shape[1]}")
print(f"解释方差比: {pca.explained_variance_ratio_.sum():.2%}")

# 查看每个主成分的解释方差
for i, ratio in enumerate(pca.explained_variance_ratio_):
    print(f"PC{i+1}: {ratio:.4f} ({ratio/pca.explained_variance_ratio_.sum():.1%})")

# 也可以指定维度
pca_2d = PCA(n_components=2)
X_2d = pca_2d.fit_transform(X)  # 用于2D可视化

# PCA的逆变换（重建）
X_reconstructed = pca.inverse_transform(X_reduced)
reconstruction_error = np.mean((X - X_reconstructed) ** 2)
print(f"重建MSE: {reconstruction_error:.6f}")
```

**PCA完整实现（从零开始）**：

```python
class MyPCA:
    """PCA的完整实现"""
    def __init__(self, n_components=None):
        self.n_components = n_components
    
    def fit(self, X):
        # 1. 中心化
        self.mean_ = X.mean(axis=0)
        X_centered = X - self.mean_
        
        # 2. 计算协方差矩阵
        n = X.shape[0]
        cov = X_centered.T @ X_centered / (n - 1)
        
        # 3. 特征分解
        eigenvalues, eigenvectors = np.linalg.eigh(cov)
        
        # 4. 按特征值从大到小排序
        sorted_idx = np.argsort(eigenvalues)[::-1]
        eigenvalues = eigenvalues[sorted_idx]
        eigenvectors = eigenvectors[:, sorted_idx]
        
        # 5. 选择前k个
        if self.n_components is None:
            self.n_components = X.shape[1]
        self.components_ = eigenvectors[:, :self.n_components].T
        self.explained_variance_ = eigenvalues[:self.n_components]
        self.explained_variance_ratio_ = self.explained_variance_ / eigenvalues.sum()
        
        return self
    
    def transform(self, X):
        return (X - self.mean_) @ self.components_.T
    
    def fit_transform(self, X):
        self.fit(X)
        return self.transform(X)
    
    def inverse_transform(self, Z):
        return Z @ self.components_ + self.mean_
```

**PCA的应用场景**：

| 场景 | 目的 | 说明 |
|------|------|------|
| **数据可视化** | 降到2-3维 | 高维数据无法直接可视化 |
| **降噪** | 去掉小特征值方向 | 噪声通常分布在方差小的方向 |
| **特征压缩** | 减少特征数 | 加速模型训练，减少内存 |
| **多重共线性** | 去除特征相关性 | PCA后各主成分正交（不相关） |
| **人脸识别** | Eigenfaces | 人脸图像降维为"特征脸" |

**PCA vs 其他降维方法**：

| 方法 | 类型 | 保持全局结构 | 保持局部结构 | 速度 | 可逆 |
|------|------|------------|------------|------|------|
| **PCA** | 线性 | ✅ | ❌ | 快 | ✅ |
| **t-SNE** | 非线性 | ❌ | ✅ | 慢 | ❌ |
| **UMAP** | 非线性 | 部分 | ✅ | 中 | ❌ |
| **Autoencoder** | 非线性 | 部分 | 部分 | 中 | ✅ |

### 4.3 t-SNE 详解

**核心思想**：使高维空间中相似的点在低维空间中也相似，不相似的点也不相似。

**算法原理**：

1. **高维空间**：用高斯分布计算点对之间的相似度（条件概率）
   $$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i}\exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}$$

2. **低维空间**：用t分布（长尾）计算点对之间的相似度
   $$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l}(1 + \|y_k - y_l\|^2)^{-1}}$$

3. **优化目标**：最小化两个分布的KL散度
   $$C = \sum_i KL(P_i \| Q_i) = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

**为什么用t分布而不是高斯分布？**

高维空间的距离在低维空间会"拥挤"——很多点对会被映射到相似的距离。t分布的长尾特性使得中等距离的点在低维空间被推得更远，从而更好地展示簇的分离。

**关键参数**：
- **perplexity**：控制有效邻居数量（5-50，通常30），可理解为每个点期望有多少个"近邻"
- **learning_rate**：通常10-1000，太大则损失函数震荡，太小则陷入局部最优
- **n_iter**：至少1000次迭代

**重要注意事项**：
1. t-SNE结果不可复现（随机初始化）
2. 簇间距离不可比较
3. 不能用于新数据的投影
4. 主要用于可视化，不是特征提取
5. 建议先用PCA降到50维再用t-SNE（加速+降噪）

```python
from sklearn.manifold import TSNE

# 先PCA降噪，再t-SNE可视化

X_pca = pca.fit_transform(X)

tsne = TSNE(n_components=2, perplexity=30, learning_rate=200, n_iter=1000, random_state=42)
X_2d = tsne.fit_transform(X_pca)

```

### 4.4 UMAP 简介

UMAP是t-SNE的更快替代，且更好地保持全局结构：

```python
import umap

# UMAP降维
reducer = umap.UMAP(n_neighbors=15, min_dist=0.1, n_components=2)
X_2d = reducer.fit_transform(X)

# 参数：
# n_neighbors：类似perplexity，控制局部vs全局结构的平衡
#   小值(5)→更关注局部结构；大值(50)→更关注全局结构
# min_dist：低维空间中点的最小距离
#   小值(0.001)→簇更紧密；大值(0.5)→簇更分散
```

**t-SNE vs UMAP选择**：
- 数据量 < 10K → 两者都可以
- 数据量 > 100K → UMAP（t-SNE太慢）
- 需要保持全局结构 → UMAP
- 需要可视化效果更好 → 试两者，选效果好的

## 五、模型评估详解

### 5.1 混淆矩阵

```
                 预测正  预测负
实际正    TP       FN
实际负    FP       TN
```

| 指标 | 公式 | 直觉 | 关注场景 |
|------|------|------|---------|
| **准确率(Accuracy)** | (TP+TN)/(TP+FP+FN+TN) | 整体正确率 | 类别均衡时 |
| **精确率(Precision)** | TP/(TP+FP) | 预测为正中真正为正的比例 | 垃圾邮件（不能误杀） |
| **召回率(Recall)** | TP/(TP+FN) | 真正为正中被正确预测的比例 | 癌症检测（不能漏诊） |
| **F1分数** | 2PR/(P+R) | P和R的调和平均 | P和R都重要时 |
| **Fβ分数** | (1+β²)PR/(β²P+R) | β>1更重R，β<1更重P | 可调权重 |

**准确率的陷阱**：当数据极度不平衡时，准确率会误导。

例如：1000个样本中990个负样本，10个正样本。全预测为负，准确率仍有99%！此时应关注F1、AUC等指标。

**不同场景的关注点**：

| 场景 | 更关注 | 原因 |
|------|--------|------|
| **垃圾邮件** | 精确率 | 不能把正常邮件误判为垃圾邮件 |
| **癌症检测** | 召回率 | 不能漏掉任何一例癌症 |
| **搜索排序** | 精确率@K | 前10个结果要准确 |
| **欺诈检测** | 召回率 | 宁可误报不可漏报 |

### 5.2 ROC曲线与AUC

**ROC曲线**：以FPR为横轴、TPR为纵轴画的曲线。通过调整分类阈值，得到一系列(FPR, TPR)点。

```
TPR(真阳性率) = TP/(TP+FN) = 召回率
FPR(假阳性率) = FP/(FP+TN) = 误报率

理想情况：TPR=1, FPR=0 → 左上角
随机猜测：沿对角线
```

- **AUC = 1.0**：完美分类器
- **AUC = 0.5**：随机猜测
- **AUC > 0.9**：优秀分类器
- **0.7 < AUC < 0.9**：中等分类器

**AUC的概率解释**：AUC等于随机取一个正样本和一个负样本，分类器将正样本排在负样本前面的概率。

**ROC vs PR曲线**：

| 维度 | ROC曲线 | PR曲线 |
|------|---------|--------|
| **适用** | 类别相对均衡 | 类别严重不平衡 |
| **关注** | 整体分类能力 | 正类表现 |
| **对不平衡敏感** | 不敏感 | 敏感 |
| **基准线** | 对角线(AUC=0.5) | 水平线(P=正类比例) |

```python
from sklearn.metrics import (roc_curve, auc, classification_report,
                             precision_recall_curve, average_precision_score)

# 完整的评估流程
y_pred = model.predict(X_test)
y_prob = model.predict_proba(X_test)[:, 1]

# 分类报告
print(classification_report(y_test, y_pred))

# ROC曲线
fpr, tpr, thresholds_roc = roc_curve(y_test, y_prob)
roc_auc = auc(fpr, tpr)
print(f"AUC: {roc_auc:.4f}")

# PR曲线（类别不平衡时更推荐）
precision, recall, thresholds_pr = precision_recall_curve(y_test, y_prob)
ap = average_precision_score(y_test, y_prob)
print(f"AP: {ap:.4f}")

# 找到最优阈值（Youden's J = TPR - FPR 的最大值）
j_scores = tpr - fpr
best_threshold = thresholds_roc[np.argmax(j_scores)]
print(f"最优阈值: {best_threshold:.4f}")
```

### 5.3 交叉验证

**为什么需要交叉验证？** 单次划分训练/测试集的结果依赖于划分方式，可能运气好或差。交叉验证通过多次划分获得更可靠的评估。

| 验证方式 | 原理 | 适用场景 | 计算量 |
|---------|------|---------|--------|
| **Hold-out** | 单次划分 | 数据量大 | 1x |
| **K-Fold** | 分K份，轮流作测试集 | 通用 | Kx |
| **Stratified K-Fold** | 保持各类比例的K-Fold | 分类问题（尤其不平衡） | Kx |
| **Time Series Split** | 按时间划分，不泄露未来信息 | 时间序列 | Kx |
| **Leave-One-Out** | 每次留1个样本 | 数据极少 | Nx |

```python
from sklearn.model_selection import cross_val_score, StratifiedKFold, GridSearchCV, TimeSeriesSplit

# K折交叉验证
scores = cross_val_score(model, X, y, cv=5, scoring='accuracy')
print(f"5折交叉验证: {scores.mean():.3f} ± {scores.std():.3f}")

# 分层K折（保持各类别比例）
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# 时间序列交叉验证
tscv = TimeSeriesSplit(n_splits=5)
# 每次用前面的数据训练，后面的数据测试，不泄露未来信息

# 网格搜索 + 交叉验证
param_grid = {
    'n_estimators': [50, 100, 200],
    'max_depth': [5, 10, 20],
    'learning_rate': [0.01, 0.1, 0.2]
}
grid_search = GridSearchCV(
    GradientBoostingClassifier(), 
    param_grid, cv=5, scoring='f1', n_jobs=-1
)
grid_search.fit(X_train, y_train)
print(f"最佳参数: {grid_search.best_params_}")
print(f"最佳分数: {grid_search.best_score_:.4f}")
```

**数据泄露的常见场景**：

| 场景 | 泄露方式 | 正确做法 |
|------|---------|---------|
| **特征缩放** | 在整个数据集上fit | 在CV循环内fit |
| **特征选择** | 在整个数据集上选特征 | 在CV循环内选 |
| **Target Encoding** | 用全部数据计算目标均值 | 用训练集计算 |
| **过采样** | 在整个数据集上SMOTE | 只在训练集上SMOTE |

```python
# 正确的做法：所有预处理都在Pipeline内
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score

pipeline = Pipeline([
    ('scaler', StandardScaler()),  # 在CV内部fit
    ('clf', LogisticRegression())
])

# 这样cross_val_score会自动在每折内独立地fit scaler
scores = cross_val_score(pipeline, X, y, cv=5)
```

## 七、如何选择合适的算法？

### 7.1 决策流程

```
1. 数据量多大？
   ├── 很小（<1000） → 传统ML（SVM、随机森林）
   └── 很大（>100K） → 深度学习或XGBoost

2. 有标签吗？
   ├── 有 → 监督学习
   ├── 无 → 无监督学习
   └── 少量 → 半监督/自监督学习

3. 任务类型？
   ├── 分类 → 逻辑回归/随机森林/神经网络
   ├── 回归 → 线性回归/XGBoost/神经网络
   └── 聚类 → K-means/DBSCAN

4. 可解释性要求？
   ├── 高 → 决策树/线性模型
   └── 低 → 随机森林/深度学习

5. 实时性要求？
   ├── 高 → 线性模型/小神经网络
   └── 低 → 复杂模型/集成方法
```

### 7.2 常见问题排查

| 问题 | 可能原因 | 排查方法 |
|------|---------|---------|
| 训练集表现差 | 模型太简单、特征不足 | 增加模型复杂度、添加特征 |
| 测试集表现差 | 过拟合 | 正则化、增加数据、早停 |
| 训练不收敛 | 学习率不当、梯度问题 | 调小学习率、检查数据 |
| 训练太慢 | 模型太大、数据太多 | 减小模型、增大batch、用GPU |
